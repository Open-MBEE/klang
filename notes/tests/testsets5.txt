Description:
This test combines forall quantifiers with subtyping and set subset:

  class Car { vin : Int }
  class Honda extends Car { streetValue : Int }

  class Garage {
    cars : Set[Car]
    req r2 : forall c : Car :- c isin cars => c.vin != Null
  }

  class ChopShop extends Garage {
    goodCars : Set[Honda]
    req r4 : goodCars subset cars  // Set[Honda] subset Set[Car]
    req r5 : forall gc : Honda :- gc isin goodCars => gc.streetValue > 5000
  }

The test exercises:
- Set[Honda] subset Set[Car] (covariant set subtyping)
- Forall quantifiers with subtype iterators
- Inherited set constraints across class hierarchy
