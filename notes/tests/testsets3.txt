  @instances(3)
  class A { x : Int }

  @instances(1)
  class B {
    s1 : Set[A]
    a1 : A
    a2 : A
    a3 : A
    req s1 = Set{a1, a2}
    req s2 = Set{a | a : A :- a.x = 10 && (a = a1 || a = a2)}
  }

The test combines heap-bounded objects (@instances) with set constraints.
Both explicit set literals (Set{a1, a2}) and set comprehensions over
object types (Set{a | a : A :- ...}) are now working correctly.
